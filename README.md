# Мої 3 найкращі місця України

Навчальний статичний web-проєкт для лабораторної роботи №1.

## Файли

- `index.html` — головна сторінка
- `city-lviv.html` — сторінка Львова
- `city-kyiv.html` — сторінка Києва
- `city-karpaty.html` — сторінка Карпат
- `form.html` — HTML-форма
- `images/` — зображення

## Запуск

Відкрийте `index.html` у браузері.

## Git
